# 1. 게임 개요 / 핵심 콘셉트

## 1.1 한 줄 소개

명령 없이는 스스로 살 수도 없던 용사 아인이 동료들의 선택과 희생을 거쳐, 마지막에는 자기 의지로 죽음을 죽이는 스토리 중심 턴제 전투 JRPG.

## 1.2 핵심 콘셉트

라플라스 전기 1부는 정통 용사 서사처럼 시작하지만, 진행될수록 제국, 여신교, 마족, 죽음, 신들의 구조에 대한 의문이 커지는 이야기다.

초반의 아인은 스스로 판단하지 못한다. 명령을 기다리고 타인의 기준을 따르며, 용사답게 행동하라는 교육을 그대로 수행한다. 동료들과 함께하며 점차 선택을 배우고, 최종적으로는 누구의 명령도 없이 레오에게 향한다.

| 인물 | 아인에게 주는 변화 |
|---|---|
| 칼리프 | 명령이 아닌 선택을 감당하는 기준 |
| 연 | 살고 싶다는 마음과 그럼에도 앞으로 나아가는 힘 |
| 니아 | 세계 구조의 단서와 진실을 보는 눈 |
| 크루즈 | 만들어진 용사의 가능성과 한계 |
| 레오 | 죽음을 죽이는 행위의 끝과 대가 |

1부의 결말에서 아인은 죽음을 쓰러뜨린다. 그러나 레오는 해제 불가한 죽음의 표식을 남긴다. 아인은 살아남기 위해 레오의 심장과 심장 옆 마력기관을 먹는다. 이는 힘을 얻기 위한 보상이 아니라 죽고 싶지 않아서 선택한 생존 행위다.

## 1.3 플레이 루프

```text
거점에서 스킬·무기·보조 장비·아이템을 준비
→ 스테이지 진입
→ 적의 대상과 방향 확인
→ 정보·방어 대응
→ 속도순 행동 실행
→ 붕괴·균열과 방향 약점으로 공격 기회 생성
→ 장별 목표 달성
→ 경험치·기술점·보급·전용 장비 개량 획득
→ 다음 장 진행
```

## 1.4 핵심 재미

| 핵심 재미 | 설명 |
|---|---|
| 제한된 행동 선택 | 고유 행동, 편성 스킬 3개, 방향 방어, 보호, 아이템 중 한 번의 행동을 선택 |
| 적 행동 대응 | 대상과 방향을 기본 공개하고 행동명·부가 효과를 추가 분석 |
| 방향 기믹 | 특정 적과 보스가 스킬로 방향 방어·방향 약점을 생성 |
| 파티 역할 조합 | 전장에 존재하는 1~5명의 동료가 모두 전투에 참여 |
| 붕괴·균열 | 고정 붕괴량을 누적해 적의 행동 또는 피해 기회를 제어 |
| 준비 전략 | 3개 스킬, 연의 무기 태그, 보조 장비 1개, 공용 아이템 3종 편성 |
| 서사와 전투의 결합 | 합류·상실·단독전이 실제 조작 인원과 행동 구조를 변화시킴 |

## 1.5 핵심 금지 사항

| 금지 항목 | 이유 |
|---|---|
| 의지 게이지 | 전투 자원 과다 |
| MP·마나·마력 비용 | AP 단일 자원과 충돌 |
| 쿨타임 | AP 선택 구조와 중복 |
| 속공·중공·강공 | 고정 스킬 비용·계수와 중복 |
| 9슬롯 | 편성 강제와 UI 과밀 |
| 적 AP | 붕괴의 행동 제어 역할과 중복 |
| 아군 붕괴 게이지 | 피해와 행동 상실이 중첩되어 과도하게 가혹 |
| 붕괴 공격·붕괴 저항 능력치 | 스킬 붕괴량·게이지 최대치와 중복 |
| 명중률·확률 회피·무작위 치명타 | 정보 대응형 전투의 예측성을 훼손 |
| 일반 무기·방어구 파밍 | 국가 지원 용사 설정과 충돌 |
| 장비 제공 스킬 | 장비 교체가 스킬 편성을 파괴 |
| 일반 화폐·상점 경제 | 반복 구매·파밍 구조가 없음 |
| 유품 보상화 | 상실의 의미 약화 |
| 크루즈 생존 분기 | 17장의 서사 기능과 충돌 |
| 20장 동료 파티전 | 아인 단독 선택의 의미 약화 |
| 레오 표식 해제 | 심장 섭취의 필연성 소멸 |

# 2. 서사 구조

## 2.1 전체 구조

```text
프롤로그
→ 1막: 명령받는 용사
→ 2막: 선택을 배우는 용사
→ 3막: 마지막까지 남은 용사
→ 에필로그: 달의 서재
```

대표 질문:

> 죽음을 죽이면, 정말 끝나는가?

## 2.2 1막: 명령받는 용사

| 범위 | 프롤로그 ~ 7장 |
|---|---|
| 중심 | 아인은 명령 없이는 판단하지 못한다 |
| 핵심 관계 | 아인, 칼리프, 연 |
| 주요 변화 | 아인은 칼리프와 연을 새 행동 기준으로 받아들인다 |
| 한계 | 아직 제국과 명령 체계에 정면으로 반하지 못한다 |

칼리프는 신앙을 복종이 아니라 선택을 감당하는 기준으로 보여준다. 연은 살고 싶다는 마음을 숨기지 않으면서도 앞으로 나아간다.

## 2.3 2막: 선택을 배우는 용사

| 범위 | 8장 ~ 15장 |
|---|---|
| 중심 | 아인이 자기 판단을 시작한다 |
| 핵심 사건 | 11장 명령 거부 |
| 추가 인물 | 니아, 크루즈 |
| 주요 변화 | 다섯 명이 하나의 파티로 정립된다 |

11장에서 아인은 황제의 약과 관련된 사건에서 처음으로 자기 판단으로 명령을 거부한다. 크루즈는 이 선택 장면에 개입하지 않는다.

| 항목 | 내용 |
|---|---|
| 크루즈 합류 결정 | 11장 종료 후 |
| 크루즈 플레이어블 | 12장부터 |
| 표면적 임무 | 전력 보강 |
| 실제 기능 | 아인 감시, 대체 가능성 확인, 제국식 용사 모델 투입 |

15장은 크루즈의 합류장이 아니다. 성검 미우가 완성되고, 크루즈가 자신의 정체성을 마주하며, 아인의 바람 관련 기술이 해금되는 장이다.

## 2.4 3막: 마지막까지 남은 용사

| 범위 | 16장 ~ 20장 |
|---|---|
| 중심 | 동료들이 하나씩 사라지고 아인이 혼자 남는다 |
| 핵심 사건 | 크루즈, 연, 칼리프의 사망 |
| 최종 구조 | 20장 아인 단독 최종전 |

```text
16장: 최종 공세 진입
17장: 크루즈 사망
18장: 연 사망
19장: 칼리프 사망
20장: 아인 단독 최종전
```

| 인물 | 마지막 역할 |
|---|---|
| 크루즈 | 가장 강하기 때문에 가장 오래 남는다 |
| 연 | 가장 빠르기 때문에 마지막 돌파를 맡는다 |
| 칼리프 | 마지막 방패로 아인을 지킨다 |
| 니아 | 아인을 레오에게 전송하고 생존한다 |
| 아인 | 혼자 레오를 죽인다 |

20장에서 누구도 아인에게 레오를 죽이라고 명령하지 않는다.

## 2.5 에필로그: 달의 서재

```text
레오 격파
→ 죽음의 표식 유지
→ 레오의 심장과 마력기관 섭취
→ 종전
→ 니아가 유품 수습
→ 무의 협곡
→ 달의 서재
→ 라플라스와 대화
→ 반복 역사와 신들의 구조를 봄
→ 분노와 복수 결심
→ 기억 봉인
```

### 봉인되는 것

- 라플라스와의 대화
- 반복되는 역사
- 용사와 죽음의 구조
- 르네·맥스웰·라플라스의 계획
- 진실을 본 절망과 분노
- 복수 결심

### 남는 것

- 전쟁
- 동료들의 죽음
- 레오와 싸운 사실
- 레오의 심장과 마력기관을 먹은 사실
- 유품의 목적
- 자신이 살아남았다는 사실

외부 세계에서 20년이 지났다는 사실은 1부 마지막에서 직접 공개하지 않는다.

## 3.1 아인

초반에는 내구가 낮은 미숙한 마법사다. 땅·물·바람의 힘을 순차적으로 습득하며 공격과 회복을 동시에 담당한다.

| 시점 | 해금 |
|---|---|
| 3장 | 땅 관련 기술 |
| 4장 | 물 관련 회복·정화 기술 |
| 15장 | 바람 관련 기술 |

20장에서는 성검 미우를 강제 장착하고 레오와 단독으로 싸운다.

## 3.2 칼리프

바랄 신국 출신. 성직자형 힐러가 아니라 누가 공격을 받을지 결정하는 메인 탱커다. 전원 공통 보호 행동을 가장 안정적으로 사용하며, 강화된 방향 방어와 전용 도발 계열 스킬로 파티의 행동 기회를 보존한다.

유품: 칼리프의 나무조각.

## 3.3 연

황룡왕국 출신. 다양한 무기를 능숙하게 다루며, 장착한 무기 종류 태그에 따라 고유 행동이 변화한다. 모든 고유 행동 변형은 정보확인 기능을 유지한다.

유품: 연의 머리장식.

## 3.4 니아

세계의 진실에 가장 가까운 인물. 공간마법과 전장 관측으로 정보를 제공하고 행동 순서·대상·방향 판단을 보조한다. 20장에서 아인을 레오에게 전송한 뒤 이탈하며 생존한다.

## 3.5 크루즈

약해서 죽는 것이 아니다. 가장 강하기 때문에 가장 오래 남고, 모두를 살리기 위해 후퇴하지 않기 때문에 죽는다.

유품: 파손된 이름 없는 개인 무기. 성검 미우와 혼동되지 않도록 별도 고유명은 추후 결정한다.

- 파티가 완성되고 다시 줄어드는 과정은 실제 전투 기능의 증가와 상실로 체감시킨다.

# 5. 전투 / 스테이지 시스템

## 5.1 전투 개요

전투는 글로벌 턴 단위의 행동력 기반 턴제다. 적은 턴 시작에 행동을 확정하며, 플레이어는 공개된 대상·방향을 읽고 정보확인과 방어 대응을 결정한다. 대응하지 않은 유닛과 적은 속도순으로 행동한다.

핵심 축:

```text
AP 관리
+ 적 행동 사전 공개
+ 정보·방어 대응
+ 속도순 행동
+ 방향 방어·약점
+ 붕괴·균열
```

## 5.2 유닛 행동 선택지

아군 유닛의 주요 행동 선택지는 7개다.

| 위치 | 행동 |
|---|---|
| 1 | 고유 행동 |
| 2 | 편성 스킬 1 |
| 3 | 편성 스킬 2 |
| 4 | 편성 스킬 3 |
| 5 | 방향 방어 |
| 6 | 보호 |
| 7 | 아이템 |

보조 조작:

- 차례 종료: AP 0, 효과 없음, 행동 종료

### 고유 행동

- 모든 플레이어블 유닛이 하나씩 가진다.
- 기본 공격을 완전히 대체한다.
- 교체·장착할 수 없다.
- 캐릭터의 기본 행동과 핵심 역할을 함께 표현한다.
- 원칙적 AP 비용은 1이다.
- 스토리 또는 장비 태그로 변형될 수 있으나 슬롯을 점유하지 않는다.
- 정확한 유닛별 고유 행동은 별도 스킬 설계 문서에서 확정한다.

### 일반 스킬 슬롯

- 모든 유닛은 처음부터 3개 슬롯을 가진다.
- 해금한 일반 스킬 중 3개를 전투 전에 편성한다.
- 슬롯에는 방향·무기 종류 제한을 기본적으로 두지 않는다.
- 속공·중공·강공 구분은 없다.

### 보호 고정 행동

- 모든 플레이어블 아군이 공통으로 보유한다.
- 일반 스킬 슬롯을 점유하지 않는다.
- AP 1과 해당 글로벌 턴의 행동 1회를 소모한다.
- 방어 대응 단계에서 자신을 제외한 아군 1명을 지정한다.
- 캐릭터의 내구와 현재 HP에 따라 실제 사용 가치가 달라진다.
- 아인·니아 같은 저내구 유닛은 위험 부담 때문에 중요한 순간에만 사용하며, 칼리프·크루즈는 탱커 역할로 더 자주 활용할 수 있다.

## 5.3 턴 진행 구조

```text
1. 글로벌 턴 시작
2. 모든 생존 아군 AP +2, 최대 6 적용
3. 적 행동·대상·방향 결정
4. 기본 정보 공개: 대상·방향
5. 정보 대응 단계
6. 방어 대응 단계
7. 대응하지 않은 유닛과 적의 속도순 행동 실행
8. 턴 종료 상태 처리
9. 승리·패배·웨이브 전환 판정
```

### 정보 대응

- 정보형 고유 행동은 방어 선언 전에 사용한다.
- AP와 해당 유닛의 이번 턴 행동을 소모한다.
- 행동명과 주요 부가 효과를 즉시 공개한다.
- 대응한 유닛은 속도순 실행 단계에서 다시 행동하지 않는다.

### 방어 대응

사용 가능 행동:

- 상단 방어
- 중단 방어
- 하단 방어
- 보호
- `방어 대응 가능`으로 지정된 캐릭터 전용 스킬

공통 규칙:

- AP와 해당 턴 행동을 소모한다.
- 현재 글로벌 턴 종료까지 유지한다.
- 속도와 무관하게 적의 첫 행동 전에 선언할 수 있다.

`방어 대응 가능` 스킬은 캐릭터별 일반 스킬 또는 고유 행동으로만 제공한다. 도발 계열 효과는 이 방식으로 칼리프·크루즈 등의 역할을 차별화하며, 모든 아군의 공통 행동으로 제공하지 않는다.

## 5.4 AP 규칙

| 항목 | 규칙 |
|---|---|
| 관리 단위 | 아군 유닛별 개별 AP |
| 최대 AP | 6 고정 |
| 전투 시작 AP | 6 |
| 회복 시점 | 글로벌 턴 시작 시 일괄 회복 |
| 회복량 | +2 |
| 첫 턴 | 동일하게 회복 처리 후 최대치에서 절삭 |
| 웨이브 전환 | 현재 AP 유지 |
| 최대 AP 성장 | 없음 |

행동별 권장 비용:

| 행동 | 권장 AP |
|---|---:|
| 고유 행동 | 1 |
| 일반 주력 스킬 | 2 |
| 강한 스킬 | 3~4 |
| 특수 고출력 스킬 | 5~6 |
| 방향 방어 | 1 |
| 보호 | 1 |
| 아이템 | 0 |
| 차례 종료 | 0 |

현재 AP보다 비용이 높은 행동은 선택할 수 없다.

적은 AP를 사용하지 않는다. 모든 생존 적은 원칙적으로 글로벌 턴마다 행동 한 번을 가진다. 강한 행동의 빈도는 패턴·턴 수·HP·페이즈·준비 행동으로 통제한다.

## 5.6 피해·회복·보호막 계산

### 피해

```text
기본 피해
= 공격력 × 스킬 피해계수 + 스킬 고정 피해
```

```text
방어 보정
= 100 ÷ (100 + 대상 방어력)
```

```text
최종 피해
= 기본 피해
× 방어 보정
× 방향 보정
× 붕괴·균열 보정
× 기타 최종 보정
```

처리 순서:

1. 공격력·피해계수·고정 피해
2. 방어력
3. 방향 방어 또는 방향 약점
4. 붕괴·균열 피해 증가
5. 기타 명시적 보정
6. 소수점 버림
7. 최소 피해 1

잠정 프로토타입 값:

| 보정 | 배율 |
|---|---:|
| 방어 없음 | 1.00 |
| 방향 불일치 방어 | 0.75 |
| 방향 일치 방어 | 0.30 |
| 방향 약점 | 1.25 |
| 붕괴·균열 | 1.50 |

수치는 데이터로 분리하고 플레이테스트에서 조정한다.

### 회복

```text
회복량
= 사용자 공격력 × 회복계수 + 고정 회복량
```

- 방어·방향·붕괴·균열의 영향을 받지 않는다.
- 중독 등 명시적 받는 회복량 보정만 마지막에 적용한다.

### 보호막

```text
보호막량
= 사용자 공격력 × 보호막계수 + 고정 보호막량
```

- 모든 피해 보정이 끝난 최종 피해를 먼저 흡수한다.
- 웨이브 종료 시 제거한다.

### 무작위 요소

사용하지 않는다.

- 명중률 없음
- 확률 회피 없음
- 무작위 치명타 없음
- 피해 편차 없음

치명타에 해당하는 강한 결과는 조건부 피해 증가로 설계한다.

## 5.7 방향 시스템

공격 방향:

- 상단
- 중단
- 하단
- 방향 없음

원칙:

- 직접 피해 공격은 하나의 고정 방향을 가진다.
- 회복·정화·보호·정보 행동과 도발 계열 스킬은 방향 없음이다.
- 범위 공격도 하나의 고정 방향을 가진다.
- 방향은 피해량·AP·붕괴량의 공통 성격을 결정하지 않는다.
- 캐릭터 하나가 세 방향을 모두 보유할 필요는 없다.
- 파티 전체의 방향 분포로 대응 범위를 만든다.

### 방향 방어

- 대응 단계에서 상·중·하 중 하나를 선택한다.
- AP 1과 해당 턴 행동을 소모한다.
- 일치 방향은 높은 피해 감소, 불일치는 낮은 피해 감소를 받는다.
- 방향 없는 직접 공격은 일반 스킬에서 사용하지 않는다.
- 회피 불가·방향 무시 기술은 명확히 예고된 특수 기술로 제한한다.

### 적 방향 방어·방향 약점

일반 적에게 상시 부여하지 않는다. 특정 유닛·정예·보스가 스킬 또는 자세로 사용한다.

예시:

```text
방패 자세
→ 상단 방어
→ 하단 약점
```

- 방어·약점 방향은 UI에 공개한다.
- 페이즈·스킬·자세에 따라 변화한다.
- 방향 약점은 공격 편성에 전략적 의미를 부여하되 모든 전투에 강제하지 않는다.

## 5.8 적 정보 공개

### 기본 공개

- 예정 대상
- 공격 방향

### 정보확인 후 공개

- 행동명
- 주요 부가 효과
- 특수 대상 규칙
- 회피 불가 여부
- 명시적 상태 면역 등 필요한 정보

행동명만 공개해 방향을 추론하는 구조가 아니라, 방향은 기본 전투 정보로 제공한다.

연과 니아는 정보 기능을 가진 고유 행동을 사용한다. 정확한 범위와 차이는 별도 캐릭터 스킬 설계에서 확정한다.

## 5.9 보호와 스킬 기반 대상 변경

### 보호

- 모든 플레이어블 아군이 공통으로 보유하는 고정 행동이다.
- 일반 스킬 슬롯을 점유하지 않는다.
- AP 1과 해당 글로벌 턴의 행동 1회를 소모한다.
- 방어 대응 단계에서 자신을 제외한 아군 1명을 지정한다.
- 지정 아군에게 들어오는 단일 대상 직접 공격의 최종 피격 대상을 보호자로 변경한다.
- 범위 공격과 피해 없는 디버프에는 적용하지 않는다.
- 피해와 동반 상태이상은 보호자에게 이전된다.
- 보호자가 전투불능이면 즉시 종료한다.
- 아인·니아처럼 내구가 낮은 유닛도 사용할 수 있으나, 대신 피격을 감당해야 하므로 중요한 상황에서만 선택하는 행동이 된다.
- 칼리프와 크루즈는 높은 내구와 전용 스킬을 통해 보호를 더 안정적으로 운용한다.

### 도발 계열 스킬

- 도발은 모든 아군이 사용할 수 있는 공통 고정 행동으로 두지 않는다.
- 칼리프와 크루즈 등 탱커 역할을 가진 캐릭터의 일반 스킬 또는 고유 행동 효과로만 제공할 수 있다.
- 적의 단일 대상 행동을 사용자 또는 지정 대상으로 변경하는 효과를 기본으로 한다.
- 실제 대상 범위·지속시간·AP 비용·면역 규칙은 개별 스킬 데이터에서 정한다.
- 적 행동 전에 사용해야 하는 도발 계열 스킬은 `방어 대응 가능` 속성을 가진다.
- 방어 대응 단계에서 사용하면 스킬 AP와 해당 턴 행동 1회를 소모하며, 이후 속도순 단계에서 다시 행동하지 않는다.
- 고정 대상 기술·대상 변경 면역 행동에는 적용하지 않으며, 관련 정보는 적 정보 UI에 공개한다.

### 대상 처리 순서

```text
1. 고정 대상·대상 변경 면역 확인
2. 스킬 기반 대상 변경 적용
3. 보호 적용
4. 최종 대상 생존 확인
5. 회피 판정
6. 방향 방어 판정
7. 피해·상태 적용
```

## 5.10 붕괴와 균열

### 대상

| 대상 | 시스템 |
|---|---|
| 일반·정예 적 | 붕괴 게이지 |
| 보스 | 균열 게이지 |
| 아군 | 해당 없음 |

### 누적

각 공격 스킬은 고정된 `붕괴량`을 가진다.

```text
최종 붕괴 누적량
= 스킬 데이터의 붕괴량
```

- 공격력과 곱하지 않는다.
- 방어력과 방향의 영향을 받지 않는다.
- 붕괴 저항 능력치는 없다.
- 적의 저항은 게이지 최대치로 표현한다.
- 붕괴량 0인 공격을 허용한다.

### 발생 처리

```text
피해 처리
→ 사망 판정
→ 생존 시 붕괴량 누적
→ 임계치 도달 시 붕괴·균열 발생
```

- 발생시킨 공격 자체에는 피해 증가를 소급 적용하지 않는다.
- 현재 실행 중인 행동은 중간에 끊지 않는다.
- 사망과 동시에 임계치에 도달하면 상태를 발생시키지 않는다.

### 붕괴

- 적이 아직 행동하지 않았다면 해당 글로벌 턴의 예정 행동을 취소한다.
- 이미 행동했다면 행동 취소는 발생하지 않는다.
- 발생 순간부터 다음 글로벌 턴 종료까지 받는 피해가 증가한다.

### 균열

- 보스 행동을 취소하지 않는다.
- 발생 순간부터 다음 글로벌 턴 종료까지 받는 피해가 증가한다.

### 게이지 처리

- 발생 시 게이지를 0으로 초기화한다.
- 초과 누적량은 삭제한다.
- 상태 중 추가 누적은 불가능하다.
- 상태 해제 후 다시 누적할 수 있다.

## 5.11 회피

회피는 확률이 아닌 횟수형 전투 상태다.

| 항목 | 규칙 |
|---|---|
| 최대 횟수 | 3회 |
| 일반 부여량 | 1회 |
| 강한 기술 | 최대 2회 |
| 지속 | 적용 순간부터 다음 글로벌 턴 종료까지 |
| 재적용 | 횟수 가산, 최대 3, 지속시간 갱신 |

- 회피 1회는 다단 공격을 포함한 스킬 행동 하나 전체를 무효화한다.
- 범위 공격은 대상별로 회피를 판정한다.
- 스킬 기반 대상 변경과 보호로 최종 대상을 결정한 뒤 회피를 판정한다.
- 회피 후 남은 공격에 방향 방어를 적용한다.
- 직접 피해와 해당 피해에 동반된 상태이상을 모두 무효화한다.

회피하지 못하는 것:

- 피해 없는 디버프
- 이미 적용된 화상·중독
- 지형·환경·장치 피해
- 죽음의 표식 등 특수 상태
- 명시적인 회피 불가 기술

적 회피는 특정 적의 스킬·자세로만 사용하며 횟수와 만료 시점을 공개한다.

## 5.12 상태이상

### 분류

| 분류 | 포함 |
|---|---|
| 일반 상태이상 | 화상, 중독, 둔화, 방어 저하, AP 회복 저하, 기술 봉쇄 |
| 전투 상태 | 방향 방어, 방향 약점, 보호, 회피, 보호막, 일시 강화, 스킬 기반 대상 변경 효과 |
| 특수 상태 | 붕괴, 균열, 죽음의 표식, 보스·스테이지 고유 상태 |

일반 정화는 일반 상태이상만 제거한다.

### 화상

- 높은 지속 피해
- 짧은 지속시간
- 적용 다음 글로벌 턴 종료부터 피해 발생

### 중독

- 낮은 지속 피해
- 긴 지속시간
- 받는 회복량 감소 포함
- 화상과 동시에 적용 가능

### 동일 상태 중첩

- 동일 상태끼리는 피해량·수치를 합산하지 않는다.
- 더 강한 효과를 유지한다.
- 더 긴 지속시간으로 갱신한다.
- 화상과 중독은 서로 다른 상태이므로 독립적으로 피해를 준다.

### 둔화

- 다음 글로벌 턴의 속도 계산부터 적용한다.
- 현재 턴 행동 순서를 재정렬하지 않는다.

### 방어 저하

- 방어 능력치를 낮춘다.
- 붕괴·균열의 최종 피해 증가와 구분한다.

### AP 회복 저하

- 글로벌 턴 시작 회복량을 +2에서 +1로 낮춘다.
- 현재 AP를 직접 감소시키지 않는다.
- 회복량 0은 보스 전용 특수 상태로 제한한다.

### 기술 봉쇄

- 기존 침묵을 대체한다.
- 편성 스킬 3개를 사용할 수 없다.
- 고유 행동·방향 방어·아이템·차례 종료는 사용할 수 있다.

### 공포

공통 상태이상으로 사용하지 않는다. 보스 고유 상태로만 설계하고 실제 효과를 명시한다.

### 적용과 면역

- 상태 적용 확률과 상태 저항 능력치는 사용하지 않는다.
- 적중하고 조건을 충족하면 확정 적용한다.
- 면역은 적 데이터에 명시한다.
- 정보 UI에서 필요한 면역을 공개한다.

### 지속 피해 계산

- 적용 시 사용자의 공격력과 상태 계수로 한 번 계산해 저장한다.
- 이후 공격력 변화의 영향을 받지 않는다.
- 방어·방향·붕괴·균열 보정을 받지 않는다.

## 5.13 다단 공격

- 계산상 하나의 스킬 행동이다.
- 전체 피해계수로 총피해를 계산한다.
- 연출에서 여러 타격으로 분할 표시할 수 있다.
- 회피 1회, 붕괴량 1회, 상태 적용 1회, 보호 판정 1회만 처리한다.

## 5.14 예상 결과 UI

행동 선택 시 다음을 표시한다.

- 예상 피해
- 예상 회복·보호막
- 예상 붕괴량
- 방향 방어·약점 적용 여부
- 붕괴·균열 피해 증가 여부
- 상태 부여 여부

공개되지 않은 특수 패시브가 있으면 정확 수치 대신 경고를 표시할 수 있다.

## 5.15 아이템

### 편성

- 파티 공용 전투 아이템 슬롯 3개
- 슬롯마다 아이템 종류 하나 편성
- 아이템별 수량은 파티 전체가 공유

### 사용

- AP 0
- 행동 1회 소모
- 속도순 실행 단계에서 사용
- 대응 단계에서는 사용하지 않는다.

### 종류

- HP 회복
- 화상·중독·일반 상태 해제
- 제한적 AP 회복
- 회피·보호막·정보 공개 등 약한 전술 보조

### 제한

- 아인의 회복·정화보다 효율이 낮아야 한다.
- 전투불능을 현재 웨이브에서 해제할 수 없다.
- 아이템 수량은 웨이브 사이에 복구하지 않는다.
- 일반 적 드롭과 반복 구매는 사용하지 않는다.
- 병참 보급·지역 세력 지원·추가 목표로 확보한다.

## 5.16 전투불능

아군 HP가 0이 되면 실제 사망이 아니라 해당 웨이브의 전투불능으로 처리한다.

전투불능 유닛:

- 행동·대응·아이템 사용 불가
- AP 회복 불가
- 패시브·연결 유지 효과 정지
- 적 대상 지정 불가
- 현재 웨이브에서 복귀 불가

다음 웨이브 시작:

- HP 1로 복귀
- 전투불능 직전 AP 유지
- 글로벌 턴 시작 AP +2 정상 적용
- 일반 상태이상과 전투 상태 제거
- 특수 상태는 개별 규칙에 따라 유지
- 자동 무적·회피·보호막 없음

현재 웨이브에서 모든 아군이 전투불능이면 즉시 패배한다.

마지막 웨이브 승리 후 전투불능 유닛도 HP 1로 복귀한다.

## 5.17 웨이브 전환

### 유지

- 생존 유닛 현재 HP
- 모든 유닛 현재 AP
- 생존 유닛의 일반 상태이상과 남은 지속시간
- 공용 아이템 잔여 수량

### 제거

- 방향 방어
- 보호·스킬 기반 대상 변경 효과
- 회피
- 보호막
- 일시 공격·방어·속도 강화
- 다음 공격 강화
- 적의 방향 자세

### 추가 규칙

- 웨이브 전환 자체에서는 지속 피해와 지속시간 감소가 발생하지 않는다.
- 동일 보스의 페이즈 전환 시 붕괴·균열 상태·게이지·자세를 초기화한다.
- 마지막 적과 모든 아군이 같은 행동 처리에서 동시에 HP 0이면 패배한다.

### 전환 순서

```text
1. 마지막 행동 전체 처리
2. 사망·전투불능 판정
3. 아군 전멸 확인
4. 웨이브 승리 확인
5. 전투 상태 제거
6. 전투불능 유닛 HP 1 복귀
7. 복귀 유닛 일반 상태 제거
8. 생존 유닛 HP·AP·일반 상태 유지
9. 다음 웨이브 적 생성
10. 다음 글로벌 턴 시작 및 AP +2
11. 적 행동 결정
12. 대응 단계
```

## 5.18 스테이지 목표 유형

- 적 전멸
- 특정 적 격파
- 지휘관 격파
- 보호 대상 생존
- 정화
- 조사·장치 조작
- 제한 턴 내 증원 차단
- 후퇴·탈출
- 단독전
- 보스 균열 발생
- 스테이지 결말 행동 사용

장별 특수전은 신규 자원을 추가하기보다 기존 규칙을 조합한다.

# 6. 성장 / 장비 / 보상 시스템

## 6.1 성장 축

```text
레벨
→ 유닛별 고정 능력치 증가
→ 기술점 획득
→ 일반 스킬 선택 해금
```

삭제:

- 훈련점
- 능력치 자유 배분
- 최대 AP 성장
- 반복 스킬 +1·+2·+3 강화

## 6.2 레벨 성장

- 경험치가 기준치를 넘으면 레벨이 상승한다.
- 레벨별 능력치 증가량은 유닛마다 고정한다.
- 상승 대상은 최대 HP·공격력·방어력·속도다.
- 속도 성장은 행동 순서가 지나치게 자주 뒤집히지 않도록 제한한다.
- 레벨업은 스테이지 종료 결과 화면에서 일괄 처리한다.

## 6.3 기술점과 스킬 해금

- 레벨 상승 시 기술점을 받는다.
- 기술점으로 일반 스킬을 해금한다.
- 해금한 스킬 중 3개를 편성한다.
- 핵심 스킬·정령 기술·고유 행동 강화는 스토리로 자동 해금한다.
- 레벨은 필요 시 기술군 접근 조건으로만 사용한다.
- 대부분의 일반 스킬 비용은 기술점 1~2를 기준으로 한다.

## 6.4 신규 합류 유닛

- 합류 장의 기준 레벨로 참가한다.
- 해당 레벨에 맞는 기술점과 필수 스킬을 받는다.
- 합류 직후 플레이어가 일반 스킬 해금을 선택할 수 있다.
- 합류 전 경험치를 가상 누적하는 시스템은 사용하지 않는다.

## 6.5 전용 장비 체계

국가와 소속 세력의 지원을 받는 용사들이므로 일반 상점 무기·방어구 파밍을 사용하지 않는다.

### 전용 무기

- 각 캐릭터의 출신·소속·설정에 맞는 전용 무기를 사용한다.
- 스토리와 세력 지원에 따라 2~3단계로 개량한다.
- 강화 실패·랜덤 옵션·반복 재료 파밍은 없다.
- 장비는 새로운 행동 버튼을 제공하지 않는다.

### 전용 방어구

- 캐릭터 전용 고정 장비로 처리한다.
- 별도 부위 교체를 사용하지 않는다.
- 스토리 개량과 레벨 성장에 능력치를 반영한다.

## 6.6 연의 무기 태그

연은 예외적으로 복수 종류의 특제 무기를 교체할 수 있다.

규칙:

- 무기 하나는 전투용 주 태그 하나를 가진다.
- 예: 검, 활, 창·둔기 계열.
- 전투 준비 단계에서만 교체한다.
- 장착 태그에 따라 연의 고유 행동 이름·아이콘·방향·피해·붕괴량·정보 범위·부가 효과가 변한다.
- 모든 변형은 행동명과 주요 부가 효과를 공개하는 정보 기능을 유지한다.
- 일반 스킬 3개는 무기 태그와 독립적이다.
- 지원하지 않는 태그의 무기는 연이 장착할 수 없다.

장비가 스킬을 제공하는 것이 아니라 연의 고유 행동이 무기에 맞게 변형되는 구조다.

## 6.7 보조 장비

- 유닛별 보조 장비 슬롯 1개
- 완성품으로 획득
- 능력치 또는 조건부 패시브 제공
- 스킬 추가 없음
- 강화 없음
- 랜덤 옵션 없음

획득 출처:

- 국가 병참부 지급
- 지역 세력 협력
- 난쟁이 제작품
- 정령 계약 매개체
- 주요 임무 보상
- 인물의 유품이 아닌 일반 증표·부품

유품은 보조 장비로 사용하지 않는다.

## 6.8 경험치 배분

- 스테이지에 참여 가능한 플레이어블 아군 전원에게 동일 경험치를 지급한다.
- 전투불능 유닛도 전부 받는다.
- 처치·피해·행동별 경험치 분배는 없다.
- 전투 중 레벨업은 없다.

## 6.9 보상

기본 보상:

- 경험치
- 레벨업에 따른 기술점
- 아이템 보급
- 신규 아이템 품목 해금

주요 일회성 보상:

- 보조 장비
- 전용 무기 개량
- 연의 신규 무기 태그
- 스토리 스킬
- 기술군 개방
- 일상 이벤트
- 설정 자료

## 6.10 경제와 반복 플레이

- 일반 화폐 삭제
- 일반 상점 삭제
- 무작위 드롭 삭제
- 반복 파밍 삭제
- 최초 클리어에만 성장 보상 지급
- 재도전은 스토리 재감상·전투 연습·다른 편성 시험용
- 스테이지 등급제 없음
- 추가 목표는 일회성 보조 보상만 지급
- 핵심 레벨·스토리 스킬을 추가 목표에 묶지 않는다.

## 6.11 유품

유품은 시스템 보상이 아니다.

- 장비로 장착하지 않는다.
- 능력치와 패시브를 주지 않는다.
- 스킬을 해금하지 않는다.
- 화폐로 판매하지 않는다.
- 에필로그의 상실과 기억을 위한 연출 장치로만 사용한다.

# 7. 17장 크루즈 단독전

## 7.1 목적

크루즈가 약해서 패배하는 것이 아니라, 압도적인 힘으로 모두의 퇴로를 열고 자기 생명을 선택적으로 소모해 시로에게 치명상을 남기는 전투다.

## 7.2 삭제된 구형 구조

- 8턴 생존
- 6턴 시로 고정 참전
- 적 처치 시 AP 회복으로 연속 행동
- 턴 도달만으로 생명연소 해금

한 턴에 행동 한 번인 현 규칙에서 처치 AP 회복은 연속 처치를 만들지 못하므로 사용하지 않는다.

## 7.3 1페이즈: 포위 병력

목표:

```text
포위 병력의 정예 지휘관 격파
```

구성:

- 다수 일반 적
- 정예 지휘관 2~3명
- 순차 증원
- 일부 적의 방향 방어·방향 약점
- 일반 적은 크루즈의 광역 공격으로 1~2회 행동 내 처치

무쌍감은 추가 행동이 아니라 광역 피해·높은 계수·일반 적 다수 동시 처치로 표현한다.

## 7.4 2페이즈: 시로

- 지휘관 전멸 후 시로 등장
- 보스 균열 게이지 사용
- HP 0이 아니라 첫 균열 발생이 목표
- 방향 방어·방향 약점 자세 사용
- 일반적인 HP 격파는 불가능하거나 스테이지 목표와 무관

## 7.5 생명연소

시로에게 첫 균열이 발생하면 크루즈의 고유 행동이 `생명연소`로 변경된다.

| 항목 | 규칙 |
|---|---|
| AP | 0 |
| 대상 | 시로 |
| 조건 | 시로가 균열 상태 |
| 결과 | 시로 치명상, 크루즈 사망, 개인 무기 파손, 전투 종료 |

이는 일반 피해 스킬이 아니라 스테이지 결말 행동이다.

균열 후 시로는 다음 행동으로 크루즈를 처형할 공격을 준비한다. 목표를 `생명연소를 사용하라`로 갱신한다.

## 7.6 실패

- 지휘관 격파 전 크루즈 전투불능
- 시로 균열 전 크루즈 전투불능
- 균열 후 생명연소를 사용하지 못하고 처형당함

실패 시 스토리는 진행하지 않고 전투를 재시작한다.

# 8. 20장 최종전 / 에필로그

## 8.1 고정 조건

- 아인 단독 조작
- 레오와 2페이즈 전투
- 성검 미우 강제 장착
- 동료 파티 개입 없음
- 죽음의 표식 해제 불가
- 레오 격파 후에도 표식 유지
- 심장과 마력기관 섭취는 전투 보상이 아닌 생존 행동

## 8.2 1페이즈: 플레이어가 성장시킨 아인

- 플레이어가 준비한 아인의 일반 스킬 3개·보조 장비·아이템을 사용한다.
- 목표는 레오의 첫 균열 발생이다.
- 레오는 방향 방어·방향 약점 자세를 사용한다.
- 고유 행동은 미우와 연계된 정보·안정 공격 기능을 가진다.

첫 균열 발생 후 레오가 죽음의 표식을 부여하고 2페이즈로 전환한다.

## 8.3 죽음의 표식

특수 상태:

- 정화 불가
- 아이템 해제 불가
- 방어로 차단 불가
- 전투 종료 후 유지
- 별도 고정 UI 표시

전투 효과 잠정안:

```text
글로벌 턴 종료 시
→ 전투 시작 시 최대 HP의 10%만큼 최대 HP 감소
→ 감소분은 회복 불가
→ 최대 HP 0이면 패배
```

10%는 프로토타입 값이며 목표 전투 턴 수에 따라 조정한다.

## 8.4 2페이즈: 동료 역할 계승

2페이즈 시작 시 현재 AP를 한 번 6으로 회복한다. 최대 AP와 턴당 회복량은 그대로 유지한다.

행동 세트:

| 위치 | 역할 |
|---|---|
| 고유 행동 | 아인·미우: 정보확인과 안정적 공격 |
| 스킬 1 | 아인: 회복·보호막·일반 상태 정화 |
| 스킬 2 | 연: 높은 균열량 공격 |
| 스킬 3 | 크루즈: 높은 피해 공격 |
| 방향 방어 | 칼리프: 강화된 방향 일치 방어 |
| 보호 | 아인 단독전이므로 유효 대상이 없어 비활성화 |
| 아이템 | 기존 공용 아이템 |

니아는 죽은 동료와 같은 기술 계승으로 사용하지 않는다. 아인을 레오에게 전송하고 공간을 유지한 인물로 연출한다.

칼리프 계승 방어 잠정 수치:

| 판정 | 일반 | 20장 2페이즈 |
|---|---:|---:|
| 방향 일치 | 70% 감소 | 80% 감소 |
| 방향 불일치 | 25% 감소 | 25% 감소 |

## 8.5 최종 일격

조건:

```text
레오 HP가 기준 이하
+
레오가 균열 상태
```

조건 충족 시 아인의 고유 행동이 `죽음을 베는 일격`으로 변경된다.

결과:

- 레오 격파
- 죽음의 표식 유지
- 아인 치명상
- 후속 심장 섭취 연출 진입

별도 공명 게이지나 일곱 번째 행동 버튼은 추가하지 않는다.

## 8.6 에필로그

레오 격파 후 표식이 사라지지 않는다. 아인은 살기 위해 레오의 심장과 심장 옆 마력기관을 먹는다.

이후 종전·유품 수습·무의 협곡·달의 서재·라플라스와의 대화·기억 봉인으로 이어진다.

유품은 전투 보상이나 계승 능력으로 전환하지 않는다.

# 9. 구현 명세

## 9.1 구현 원칙

- 밸런스 값은 데이터로 분리한다.
- 원본 데이터와 런타임 상태를 분리한다.
- 기획에 없는 자원·쿨타임·확률을 임의 추가하지 않는다.
- 모든 규칙은 로그 기반 프로토타입으로 먼저 검증한다.
- 전투 UI는 규칙이 검증된 뒤 제작한다.
- 사용자가 직접 설계·구현하고 AI는 검토·힌트·리뷰를 담당한다.

# 11. 플레이테스트 기준

## 11.1 핵심 전투

| 테스트 | 성공 기준 |
|---|---|
| 7개 행동 구조 | 고유 행동·3스킬·방향 방어·보호·아이템의 역할이 명확함 |
| 고유 행동 | 기본 공격보다 캐릭터성이 강하고 매 전투 의미가 있음 |
| 3스킬 편성 | 필수 스킬 세금 없이 실제 선택이 생김 |
| AP | AP 2 기술은 지속 사용, AP 3~4 기술은 비축 판단을 요구 |
| 적 intent | 대상·방향을 보고 방어 결정을 할 수 있음 |
| 정보확인 | 행동명·부가 효과를 알면 대응이 실질적으로 바뀜 |
| 대응 단계 | 모든 아군이 빠른 적보다 먼저 보호할 수 있고, 전용 대응 스킬은 지정 캐릭터만 사용 가능 |
| 속도 | 공격·회복·붕괴 순서에는 영향을 주되 방어 가능 여부는 막지 않음 |
| 방향 | 상시 가위바위보가 아니라 특정 자세·약점에서 전략적 가치 발생 |
| 붕괴 | 행동 전 발생 시 취소 보상이 명확함 |
| 균열 | 보스 행동은 유지되지만 피해 기회가 분명함 |
| 회피 | 방향 방어와 역할이 겹치지 않고 제한 자원으로 작동 |
| 상태 | 확률 실패 없이 결과를 예측할 수 있음 |
| 피해 예측 | 실제 결과와 UI 예상값이 일치 |

## 11.2 캐릭터 역할

| 캐릭터 | 성공 기준 |
|---|---|
| 아인 | 공격하면 강하지만 위험하고, 회복하면 공격 기회를 잃음 |
| 칼리프 | 공통 보호를 가장 안정적으로 사용하고, 방향 방어·전용 도발 계열 스킬로 대상 흐름을 바꿈 |
| 연 | 무기 태그로 고유 행동이 달라지며 정보·붕괴 역할은 유지됨 |
| 니아 | 정보·공간 지원이 유효하지만 보스 패턴을 완전 무력화하지 않음 |
| 크루즈 | 일반 적을 압도하면서 전용 도발 계열 스킬로 제한적인 서브 탱커 역할도 수행함 |

## 11.3 웨이브

- 전투불능은 해당 웨이브에서 충분히 무겁다.
- HP 1 복귀가 자동 승리를 보장하지 않는다.
- AP 유지가 웨이브 종료 전 자원 선택을 만든다.
- 생존 유닛의 상태 유지가 회복·정화의 가치를 만든다.
- 회피·보호막 제거로 마지막 적을 남겨 준비하는 최적화가 발생하지 않는다.
- 모든 아군 동시 전투불능 판정이 일관된다.

## 11.4 성장·장비·보상

- 레벨업만으로 캐릭터 역할이 유지된다.
- 기술점 해금에서 정답 하나만 존재하지 않는다.
- 일반 장비 파밍 없이도 스테이지 보상이 충분하다.
- 연의 무기 선택이 고유 행동을 실질적으로 변화시킨다.
- 보조 장비가 새 스킬 버튼을 만들지 않고 빌드를 보정한다.
- 경험치 동일 배분이 탱커·지원 캐릭터를 불리하게 만들지 않는다.

## 11.5 17장

성공 기준:

- 일반 병력을 압도한다.
- 정예 지휘관은 실제 전투 판단을 요구한다.
- 시로의 방향 자세와 균열을 공략한다.
- 생명연소는 전투 성과로 해금된다.
- 크루즈의 사망이 실패가 아니라 목적 달성으로 느껴진다.
- 생존 분기가 있다고 오해하지 않는다.

## 11.6 20장

성공 기준:

- 1페이즈에서 플레이어가 성장시킨 아인의 편성이 유효하다.
- 죽음의 표식이 전투 시간 압박을 만든다.
- 2페이즈의 네 동료 역할이 버튼 구조 안에서 구분된다.
- 니아의 생존과 전송 역할이 죽은 동료 계승과 구분된다.
- 레오의 방향 자세·정보·균열·피해 기회를 모두 사용한다.
- 최종 일격 조건이 명확하다.
- 레오 격파 후 표식이 남아 심장 섭취가 필연적으로 이어진다.

# 부록 B. 최종 QA 체크리스트

## 기획 일관성

- [ ] 칼리프 출신이 바랄 신국으로 표기되어 있다.

- [ ] 유품이 장비·스킬·패시브로 사용되지 않는다.

- [ ] 9슬롯·강도 관련 데이터와 UI가 없다.
- [ ] 모든 아군은 고유 행동과 일반 스킬 3개를 가진다.
- [ ] 모든 아군은 스킬 슬롯과 분리된 보호 고정 행동을 가진다.
- [ ] 공통 도발 고정 행동은 존재하지 않는다.

- [ ] 첫 턴에도 AP 회복 함수를 동일하게 호출하고 최대 6으로 절삭한다.
- [ ] 대상·방향이 대응 전에 공개된다.

- [ ] 예상 피해와 실제 피해가 일치한다.

- [ ] AP가 웨이브 사이에 유지된다.
- [ ] 전투불능 유닛이 다음 웨이브 HP 1로 복귀한다.

- [ ] 회피·보호막·대응 상태가 제거된다.
- [ ] 전원 전투불능이면 다음 웨이브로 넘어가지 않고 패배한다.

- [ ] 훈련점이 없다.
- [ ] 레벨업이 유닛별 고정 능력치와 기술점을 제공한다.

- [ ] 장비가 스킬을 직접 제공하지 않는다.
- [ ] 연 고유 행동이 무기 태그에 따라 변한다.
- [ ] 일반 화폐·상점·무작위 드롭이 없다.
- [ ] 전투불능 유닛도 경험치를 전부 받는다.

## 후반 특수전

- [ ] 17장 생명연소는 시로 균열 후 고유 행동을 교체한다.
- [ ] 20장 1페이즈는 플레이어의 아인 편성을 사용한다.
- [ ] 20장 2페이즈는 아인·연·크루즈·칼리프 역할을 고정 행동 구조 안에서 표현하며, 보호는 단독전에서 비활성화된다.
- [ ] 니아는 기술 계승이 아니라 전송·공간 유지 역할이다.
- [ ] 레오 격파 후 죽음의 표식이 유지된다.
- [ ] 심장·마력기관 섭취가 생존 행동으로 연출된다.
