# 라플라스 전기 1부 — v0.1.0 공개범위 결정문서

- 문서 상태: 최신화 확정본
- 기준 GDD: `라플라스 전기 1부 GDD v0.4 전투 시스템 재설계 통합본`
- 기준일: 2026-07-31
- 목적: 최초 공개판의 콘텐츠 범위, 필수 시스템, 완료 조건 고정

## 문서 우선순위

이 문서는 `v0.1.0`의 공개 범위와 완료 조건만 고정한다.

문서 간 내용이 충돌할 경우 다음 우선순위를 적용한다.

```text
최신 통합 GDD
→ 본 공개범위 결정문서
→ 단계별 구현 문서
→ 기존 코드와 구형 기획 문서
```

따라서 최신 통합 GDD에서 삭제된 9슬롯, 속공·중공·강공, 적 AP, 붕괴 공격·붕괴 저항, 자기 차례 방향 방어, 훈련점, 일반 장비 파밍 규칙은 본 문서에도 적용하지 않는다.

# 0. 문서 상태

| 항목 | 내용 |
|---|---|
| 상태 | 확정 |
| 목적 | 최초 공개판의 범위와 완료 기준 고정 |
| 공개 방식 | 구간 완성 후 공개하고 이후 장을 콘텐츠 업데이트로 추가 |
| 핵심 원칙 | 시스템은 완성형, 콘텐츠는 제한형 |
| 시스템 기준 | 최신 통합 GDD의 전투·성장·장비·보상 규칙 |
| 공개 범위 기준 | 프롤로그 ~ 4장 |

`시스템은 완성형`은 1부 전체에서 사용할 핵심 구조를 공개판 단계부터 확장 가능한 형태로 구현한다는 뜻이다.

`콘텐츠는 제한형`은 공개판에 필요한 캐릭터·스킬·적·장비·스테이지만 제작한다는 뜻이다.

# 1. 최초 공개판

| 항목 | 확정 내용 |
|---|---|
| 버전 | `v0.1.0` |
| 스토리 범위 | 프롤로그 ~ 4장 |
| 종료점 | 영원의 숲 정화 완료 / 물의 맹세 획득 |
| 목표 플레이 시간 | 메인 직행 3~4시간 / 일반 플레이 4~6시간 |
| 플레이 가능 아군 | 아인 / 칼리프 / 연 |
| 전투 참여 방식 | 스토리상 같은 전장에 있는 플레이어블 아군 전원 참가 |
| 전투 스테이지 | 8개 내외 |
| 보스 | 2종 |
| 일반·정예 적 | 7~10종 |
| 진행 구조 | 메뉴형 거점 → 스테이지 전투 → 보상·성장 → 다음 장 |

자유로운 출전·벤치 편성은 사용하지 않는다. 프롤로그와 장별 사건에 따라 1~3명이 참가하며, 같은 전장에 있는 플레이어블 인물은 원칙적으로 모두 조작한다.

# 2. 서사 종료 기준

```text
아인의 출발
→ 칼리프·연과 파티 형성
→ 기본 전투 규칙 습득
→ 땅의 맹세 획득
→ 영원의 숲 정화
→ 물의 맹세 획득
→ 그레이스 공작령과 포로 문제 예고
→ v0.1.0 종료
```

4장과 5장은 분위기와 갈등 축이 다르다. 따라서 4장의 정화와 맹세 획득을 현재 공개분의 결산으로 사용하고, 5장의 새로운 지역·갈등 진입은 `v0.2.0`의 시작으로 분리한다.

5장 관련 정보는 예고만 한다.

포함:

- 포로의 행방에 대한 단서
- 그레이스 공작령 관련 정보
- 다음 임무가 존재한다는 예고

미포함:

- 5장 지역으로의 실제 출발
- 5장 전투
- 비살상 제압과 경보 관리의 본격 도입
- 새로운 갈등의 직접 개시

# 3. 필수 게임 루프

```text
타이틀
→ 새 게임·이어하기
→ 메뉴형 거점
→ 스테이지 선택
→ 전투 전 대화
→ 전투 준비
→ 웨이브 전투
→ 결과·보상
→ 레벨·기술점·스킬 해금
→ 장비·아이템 정비
→ 다음 스테이지
```

## 3.1 전투 준비 항목

- 유닛별 일반 스킬 3개 편성
- 전용 무기 상태 확인
- 유닛별 보조 장비 1개 편성
- 파티 공용 전투 아이템 3종 편성
- 연의 무기 태그 선택
- 스테이지 목표와 적 정보 확인

고유 행동과 방향 방어는 고정 행동이므로 스킬 슬롯을 점유하지 않는다.

## 3.2 완주 조건

최초 공개판은 다음 조건을 만족해야 한다.

- 디버그 입력 없이 시작 가능
- 임시 Scene 직접 실행 없이 타이틀에서 시작 가능
- 프롤로그부터 4장 종료까지 정상 진행 가능
- 스테이지 실패 후 재도전 가능
- 저장 후 게임을 종료하고 이어하기 가능
- 공개분 종료 화면에서 진행 기록 저장 가능

# 4. 최초 공개 전 완성 대상

## 4.1 전투 코어

### 행동 구조

- 아군별 고유 행동 1개
- 일반 스킬 슬롯 3개
- 상단·중단·하단 방향 방어
- 파티 공용 아이템 사용
- 차례 종료
- 한 유닛은 글로벌 턴마다 행동 1회

삭제 상태:

- 기본 공격 없음
- 9슬롯 없음
- 속공·중공·강공 없음
- 스킬 강도 선택 없음

### 글로벌 턴

```text
글로벌 턴 시작
→ 생존 아군 AP 회복
→ 적 행동·대상·방향 결정
→ 대상·방향 기본 공개
→ 정보 대응
→ 방어 대응
→ 대응하지 않은 유닛과 적의 속도순 행동
→ 턴 종료 상태 처리
→ 승패·웨이브 전환 판정
```

필수 처리:

- 속도순 정렬
- 속도 동률 우선순위
- 대응 행동 사용자의 재행동 방지
- 전투불능 유닛 제외
- 적 행동 불능·대상 상실 시 처리

### AP

| 항목 | 규칙 |
|---|---|
| 관리 단위 | 아군 유닛별 개별 AP |
| 최대 AP | 6 |
| 전투 시작 AP | 6 |
| 턴 시작 회복 | +2 |
| 첫 턴 | 동일한 회복 함수를 호출한 뒤 최대 6에서 절삭 |
| 웨이브 전환 | 현재 AP 유지 |
| 적 AP | 없음 |

필수 예외 처리:

- AP 부족 행동 선택 차단
- 행동 취소 시 AP 미소모
- 행동 확정 후 정상 소모
- 최대치 초과 회복 절삭
- 전투불능 유닛 AP 회복 중지

### 적 행동 정보

기본 공개:

- 예정 대상
- 공격 방향

정보확인 후 공개:

- 행동명
- 주요 부가 효과
- 특수 대상 규칙
- 회피 불가 여부
- 필요한 상태 면역 정보

연의 정보형 고유 행동을 공개판에서 사용할 수 있어야 한다.

### 대응 단계

정보 대응:

- 방어 선언 전에 실행
- AP와 해당 유닛의 행동 1회 소모
- 적 행동명과 주요 부가 효과 공개

방어 대응:

- 상단 방어
- 중단 방어
- 하단 방어
- 보호
- 도발

공통 규칙:

- 적의 첫 행동 전에 선언 가능
- 속도와 무관하게 사용 가능
- 현재 글로벌 턴 종료까지 유지
- AP와 행동 1회 소모

### 피해·회복·보호막

- 공격력·스킬 계수·고정값 기반 피해 계산
- 방어력 곡선 보정
- 방향 방어·방향 약점 보정
- 붕괴·균열 피해 증가 보정
- 소수점 버림과 최소 피해 1
- 공격력 기반 회복 계산
- 공격력 기반 보호막 계산
- 예상 피해·회복·보호막 UI

사용하지 않는 무작위 요소:

- 명중률
- 확률 회피
- 무작위 치명타
- 피해 편차

### 방향 시스템

- 공격 방향: 상단 / 중단 / 하단 / 방향 없음
- 직접 피해 공격은 고정 방향 보유
- 회복·정화·보호·도발·정보 행동은 방향 없음
- 방향 일치 방어와 불일치 방어 구분
- 특정 적·정예·보스의 방향 방어 자세
- 특정 적·정예·보스의 방향 약점
- 방향 방어·약점 UI 공개

일반 적 전체에 방향 자세를 상시 부여하지 않는다.

### 보호·도발·대상 결정

필수 처리 순서:

```text
고정 대상·도발 면역 확인
→ 도발 적용
→ 보호 적용
→ 최종 대상 생존 확인
→ 회피 판정
→ 방향 방어 판정
→ 피해·상태 적용
```

칼리프의 탱커 역할을 검증할 수 있도록 공개판부터 보호·도발을 모두 구현한다.

### 붕괴·균열

| 대상 | 시스템 |
|---|---|
| 일반·정예 적 | 붕괴 게이지 |
| 보스 | 균열 게이지 |
| 아군 | 없음 |

필수 규칙:

- 스킬별 고정 붕괴량
- 공격력·방어력·방향과 무관한 게이지 누적
- 붕괴 발생 시 아직 행동하지 않은 일반·정예 적의 행동 취소
- 균열 발생 시 보스 행동 유지
- 붕괴·균열 중 받는 피해 증가
- 발생 시 게이지 0 초기화
- 상태 중 추가 누적 금지
- 사망한 적에게 붕괴 발생 금지

### 회피

- 확률이 아닌 횟수형 상태
- 최대 3회
- 회피 1회로 스킬 행동 하나 전체 무효화
- 직접 피해와 동반 상태이상 무효화
- 피해 없는 디버프와 지속 피해는 회피 불가
- 보호·도발 적용 후 회피 판정
- 대상별 범위 공격 회피 판정

### 상태이상

공통 시스템으로 구현:

- 화상
- 중독
- 둔화
- 방어 저하
- AP 회복 저하
- 기술 봉쇄

필수 규칙:

- 확률 적용 없음
- 조건 충족 시 확정 적용
- 면역은 적 데이터에 명시
- 일반 정화는 일반 상태이상만 제거
- 화상과 중독 동시 적용 가능
- 동일 상태는 더 강한 효과와 더 긴 지속시간 유지
- 지속 피해는 적용 시 계산하여 저장

공개판 콘텐츠는 이 중 필요한 상태만 사용해도 되지만, 시스템은 이후 장에서 확장 가능해야 한다.

### 아이템

- 파티 공용 슬롯 3개
- 종류별 잔여 수량 공유
- AP 0
- 행동 1회 소모
- 속도순 실행 단계에서 사용
- 대응 단계 사용 불가
- 현재 웨이브 전투불능 해제 불가
- 웨이브 전환 시 수량 복구 없음

공개판 최소 품목:

- HP 회복 아이템
- 일반 상태 해제 아이템
- 제한적 AP 회복 또는 약한 전술 보조 아이템

### 전투불능과 웨이브

전투불능:

- HP 0인 아군은 현재 웨이브에서 이탈
- 행동·대응·아이템·AP 회복 불가
- 현재 웨이브에서 복귀 불가
- 모든 아군 전투불능 시 즉시 패배

다음 웨이브 시작:

- 전투불능 유닛 HP 1 복귀
- 전투불능 직전 AP 유지
- 턴 시작 AP +2 적용
- 복귀 유닛 일반 상태와 전투 상태 제거
- 자동 무적·회피·보호막 없음

웨이브 유지:

- 생존 유닛 현재 HP
- 모든 유닛 현재 AP
- 생존 유닛 일반 상태와 남은 지속시간
- 공용 아이템 잔여 수량

웨이브 제거:

- 방향 방어
- 보호·도발
- 회피
- 보호막
- 일시 강화
- 적 방향 자세

### 승패·동시 처리

- 아군 전멸 시 패배
- 목표 달성 시 승리
- 마지막 적과 모든 아군이 같은 행동에서 동시에 HP 0이면 패배
- 마지막 행동 전체 처리 후 승패 판정
- 웨이브 승리보다 아군 전멸 판정을 먼저 처리
- 보스 페이즈 전환 시 균열 게이지·상태·자세 초기화

## 4.2 전투 준비·성장·장비·보상

### 스킬 편성

- 모든 플레이어블 아군은 처음부터 일반 스킬 슬롯 3개 보유
- 해금한 일반 스킬 중 3개 편성
- 고유 행동은 교체 불가
- 스킬에 속공·중공·강공 구분 없음
- 스킬별 AP 비용과 피해·회복·붕괴량은 데이터로 관리

### 성장

```text
경험치 획득
→ 레벨 상승
→ 유닛별 고정 능력치 증가
→ 기술점 획득
→ 일반 스킬 선택 해금
```

필수 규칙:

- 훈련점 없음
- 능력치 자유 배분 없음
- 최대 AP 성장 없음
- 전투 중 레벨업 없음
- 스테이지 결과 화면에서 일괄 성장 처리
- 전투불능 유닛도 동일 경험치 획득
- 참여 가능한 아군 전원 동일 경험치 획득

### 스킬 해금

- 기술점으로 일반 스킬 해금
- 핵심 스킬과 정령 기술은 스토리 자동 해금
- 3장 땅 관련 기술 해금
- 4장 물 회복·정화 기술 해금
- 해금 상태 저장
- 기술점 소비와 잘못된 중복 해금 방지

복잡한 분기형 스킬 트리 UI는 필수가 아니다. 기술점으로 스킬을 선택 해금할 수 있는 기본 구조만 필요하다.

### 전용 장비

공개판에서 필요한 기본 구조:

- 캐릭터별 전용 무기
- 캐릭터별 고정 방어구
- 유닛별 보조 장비 슬롯 1개
- 장비 능력치와 조건부 패시브
- 장비가 스킬을 직접 제공하지 않는 구조
- 랜덤 옵션 없음
- 강화 실패 없음
- 반복 재료 파밍 없음

전용 무기의 전체 2~3단계 개량 콘텐츠는 공개판 필수 범위가 아니다. 이후 스토리 개량을 추가할 수 있는 데이터 구조만 마련한다.

### 연의 무기 태그

- 전투 준비 단계에서만 교체
- 장착 태그에 따라 고유 행동 변형
- 이름·아이콘·방향·피해·붕괴량·정보 범위·부가 효과 변경 가능
- 모든 변형이 정보확인 기능 유지
- 일반 스킬 3개와 독립

공개판에는 최소한 실제 선택을 검증할 수 있는 무기 태그 수를 제공한다. 최종 태그 수와 전체 무기 목록은 후속 설계 대상으로 둔다.

### 보상과 경제

포함:

- 경험치
- 레벨업에 따른 기술점
- 아이템 보급
- 신규 아이템 품목 해금
- 보조 장비
- 스토리 스킬
- 기술군 개방
- 설정 자료 또는 일상 이벤트

미포함:

- 일반 화폐
- 일반 상점
- 무작위 드롭
- 반복 파밍
- 스테이지 등급제
- 장비 강화 재료 파밍

최초 클리어에만 성장 보상을 지급한다. 재도전은 전투 연습과 다른 편성 시험을 위한 기능으로 사용한다.

# 7. 공개 완료 조건

## 7.1 진행

- [ ] 타이틀에서 새 게임을 시작할 수 있다.
- [ ] 이어하기로 마지막 저장 지점에서 재개할 수 있다.
- [ ] 프롤로그부터 4장 종료까지 진행 불가 없이 완주할 수 있다.
- [ ] 5장 본편으로 진입하지 않는다.
- [ ] 4장 종료 화면과 다음 업데이트 예고가 표시된다.
- [ ] 클리어 기록이 저장된다.
- [ ] 패배 후 정상 재도전할 수 있다.

## 7.2 전투 코어

- [ ] 9슬롯·속공·중공·강공 데이터와 UI가 없다.
- [ ] 모든 플레이어블 아군이 고유 행동과 일반 스킬 3개를 가진다.
- [ ] 아군 AP는 최대 6, 시작 6, 글로벌 턴 시작 +2 규칙을 따른다.
- [ ] 적은 AP를 사용하지 않는다.
- [ ] 적의 대상과 방향이 대응 전에 공개된다.
- [ ] 정보 대응과 방어 대응이 적의 첫 행동 전에 작동한다.
- [ ] 대응 행동을 사용한 유닛은 같은 턴에 다시 행동하지 않는다.
- [ ] 속도순 행동이 공격·회복·붕괴 처리 순서에 반영된다.
- [ ] 방향 방어·방향 약점이 UI와 계산에 반영된다.
- [ ] 보호·도발·회피·방향 방어 처리 순서가 고정되어 있다.
- [ ] 일반·정예 적은 붕괴, 보스는 균열을 사용한다.
- [ ] 아군에게 붕괴 게이지가 없다.
- [ ] 붕괴량은 스킬별 고정 수치다.
- [ ] 회피는 확률이 아닌 횟수형 상태로 작동한다.
- [ ] 상태 적용은 확률 없이 조건 충족 시 확정된다.
- [ ] 예상 결과와 실제 결과가 일치한다.

## 7.3 웨이브·전투불능

- [ ] 아군 HP 0은 현재 웨이브 전투불능으로 처리된다.
- [ ] 전투불능 유닛은 현재 웨이브에서 행동하지 못한다.
- [ ] 모든 아군 전투불능 시 즉시 패배한다.
- [ ] 다음 웨이브에서 전투불능 유닛이 HP 1로 복귀한다.
- [ ] 복귀 유닛 AP가 유지되고 턴 시작 +2를 받는다.
- [ ] 생존 유닛의 HP·AP·일반 상태가 유지된다.
- [ ] 회피·보호막·방향 방어·보호·도발은 웨이브 전환 시 제거된다.
- [ ] 동시 전멸과 마지막 적 처치 판정이 문서 규칙과 일치한다.

## 7.4 성장·장비·보상

- [ ] 레벨업 시 유닛별 고정 능력치가 상승한다.
- [ ] 레벨업 시 기술점을 획득한다.
- [ ] 기술점으로 일반 스킬을 해금할 수 있다.
- [ ] 3장 땅 기술과 4장 물 기술이 스토리로 해금된다.
- [ ] 전투불능 유닛도 동일 경험치를 받는다.
- [ ] 장비가 스킬을 직접 제공하지 않는다.
- [ ] 연의 고유 행동이 무기 태그에 따라 변형된다.
- [ ] 보조 장비 슬롯 1개가 작동한다.
- [ ] 공용 아이템 3종의 편성·수량·사용이 작동한다.
- [ ] 일반 화폐·상점·무작위 드롭·반복 파밍이 없다.
- [ ] 최초 클리어 보상이 중복 지급되지 않는다.

## 7.5 UI·저장·품질

- [ ] 모든 필수 전투 정보가 UI 또는 전투 로그에서 확인된다.
- [ ] 임시 텍스트와 디버그 입력이 제거되어 있다.
- [ ] 필수 대화·연출·BGM·효과음이 적용되어 있다.
- [ ] 최소 한 입력 체계가 전체 기능을 지원한다.
- [ ] AP·대상 선택·대응 단계·웨이브 전환에서 소프트락이 없다.
- [ ] 전투 준비·성장·장비·아이템 정보가 저장된다.
- [ ] 세이브 파일에 버전 번호가 기록된다.
- [ ] 잘못된 세이브 버전은 무시하지 않고 오류 또는 마이그레이션 안내를 제공한다.
- [ ] 공개용 빌드에서 개발 전용 Scene과 치트 기능에 접근할 수 없다.

이 조건을 충족하지 못한 빌드는 `v0.1.0`으로 공개하지 않는다.
